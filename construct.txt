wrayblog

│  │  └─ fonts/           # 自定义字体（如博客标题字体）

│  │  │  ├─ Footer.jsx
│  │  │  └─ Sidebar.jsx
│  │  └─ post/            # 文章专属组件（文章卡片、评论区）

│  │     └─ Comment.jsx

│  ├─ index.jsx           # 入口文件
│  └─ index.css           # 全局基础样式
├─ package.json           # 项目依赖配置
